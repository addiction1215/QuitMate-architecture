# QuitMate Architecture

[아키텍처 다이어그램 보기](https://addiction1215.github.io/QuitMate-architecture/)

QuitMate 서비스의 전체 시스템 구조와 주요 데이터 흐름을 비개발자도 탐색할 수 있게 정리한 정적 다이어그램입니다.

## 포함 범위

- 모바일 앱, 관리자 웹, API 서버
- MySQL·MongoDB 데이터 저장소와 통계 배치
- JWT 인증, 푸시 Outbox, 외부 연동과 관측 지점

## 갱신 방법

새 Archify HTML을 `index.html`로 교체해 기본 브랜치에 반영하면 GitHub Pages에 배포됩니다.
